# Проект TaskFlow

Реализует API для Jira-подобного приложения. Предоставляет возможность создания Рабочих пространств (Workspaces), Проектов (Projects) и Задач (Tasks)

## Основные архитектурные особенности

- **permissions:** в проекте сочетаются стандартный IsAuthenticated для всех моделей и IsWorkspaceMember для Проектов и Задач
- **IsWorkspaceMember:** кастомный класс, проверяющий принадлежность пользователя, осуществляющего запрос, к Рабочему пространству, в котором находится соответствующей Проект/соответствующая Задача
- **N+1 query problem:** для всех моделей используются select_related и prefetch_related для минимазации числа запросов к Базе Данных и предотвращения проблемы N+1 запроса
